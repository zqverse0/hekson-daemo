# 诗文与史实库

## 规则

1. **原文只从本表取**。表中标"待核"的，界面上先保留，但正式发布前必须对照权威版本（如中华书局《苏轼诗集》《苏轼词编年校注》、孔凡礼《苏轼年谱》）核对，核完把状态改成"已核"并写明来源。
2. 表里没有的诗文，不要自己补；需要时先加入本表并标"待核"。
3. 不改字：生僻字、异体字照原文（如"饘粥"），不替换成常用字。
4. 每句引文都注出处（篇名，必要时加白话释义）。
5. 写于常州以外的诗只能作为"苏轼的生活意趣"使用，不能说成常州作品。
6. 传说一律标"相传"；艺术化画面由全局页脚"画面与演出为艺术化表现，非历史场景复原"覆盖，关键处另加注。
7. 文字预算：每幕旁白 ≤ 2 行，全篇旁白 ≤ 15 行。多出来的放进可选的"注"。
